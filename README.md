# Blue VIP 📺

تطبيق **البث المباشر والأفلام والمسلسلات والمباريات** بنظام تطبيقات IPTV
الاحترافي — واجهة عربية RTL داكنة فائقة، مع لوحة إدارة PHP كاملة واشتراكات
VIP بأكواد تفعيل مرتبطة بالجهاز.

> البنية مستوحاة من التحليل البنيوي لتطبيق IPTV عراقي مشهور (نفس الباليتة
> الداكنة `0B0C10 → 13151F → 181B26`، 5 تبويبات، جدول مباريات مستقل بفلاتر
> مباشر/قادمة/منتهية، كتالوج مدمج احتياطي، نظام مصادر متعددة) مع هوية
> **Blue VIP** الخاصة بأكسنت أزرق.

## نظام التطبيق (10 شاشات)

1. **Splash + Intro** — شعار متوهج + «مرحباً بك في Blue VIP» + تاغلاين + زر
   «دخول التطبيق والاستمتاع» + زر «الانضمام لقناة التلغرام الرسمية»
2. **البث المباشر** — بحث (ابحث عن قناة، فيلم، مسلسل...) + شرائح أقسام أفقية + شبكة قنوات + قلب مفضلة
3. **الأفلام** — شبكة بوسترات بتقييم ⭐ وسنة + تشغيل مباشر
4. **المسلسلات** — ورقة الحلقات مجمعة بالموسم «اختر الحلقة»
5. **المفضلة** — القنوات المحفوظة بصفوف سريعة
6. **جدول المباريات** — فلاتر (الكل / مباشر الآن 🔴 / القادمة ⏳ / المنتهية ⚽) + شارات حالة + «اختر سيرفر البث»
7. **المشغل** — تحكم مخصص + تقدم + صوت + تبديل مصادر تلقائي عند الفشل
   («تعذر تشغيل هذا الرابط حالياً من المصدر») + «سيرفر آخر»
8. **تفعيل VIP** — إدخال كود `BV-XXXX-XXXX` + حالة الاشتراك + معرف الجهاز
9. **الإعدادات** — حالة الاشتراك + التلغرام + مزامنة + إشعار الإدارة + فحص تحديث
10. **حالات فارغة/خطأ** لكل شاشة مع «إعادة المحاولة»

## لوحة الإدارة (PHP)

دخول افتراضي: **admin / bluevip2025** (غيّره من صفحة الإعدادات فوراً).

| الصفحة | ماذا تدير |
|---|---|
| اللوحة | 8 بطاقات إحصائية + روابط الـ API + آخر التفعيلات |
| الأقسام | أقسام البث/الأفلام/المسلسلات (إضافة/تعديل/حذف + ترتيب) |
| القنوات | اسم + قسم + رابط بث m3u8/mp4 + رابط احتياطي + نشط/موقوف |
| أفلام ومسلسلات | عناصر + حلقات المسلسلات (موسم/رقم/اسم/رابط) |
| المباريات | عنوان + بطولة + وقت + حالة + سيرفرات بث لكل مباراة |
| أكواد VIP | توليد دفعات (`BV-XXXX-XXXX`) + مدة بالأيام + ملاحظة المشترك + فك جهاز (إعادة تعيين) + حذف |
| الإعدادات | اسم التطبيق + تاغلاين + تلغرام + إصدار/رابط APK + إجبار تفعيل + إشعار + حساب المدير |

الواجهة: داكنة RTL متجاوبة (جوال/تابلت/ديسكتوب) بنفس هوية التطبيق.

## الـ API العام

`php/api/index.php?action=...`

| action | الناتج |
|---|---|
| `config` | اسم التطبيق، تلغرام، إصدار، رابط APK، إجبار تفعيل، إشعار |
| `catalog` | أقسام + قنوات (نفس بنية الكتالوج المدمج) |
| `movies` / `series` | الأفلام / المسلسلات مع الحلقات |
| `matches` | المباريات مع سيرفرات البث |
| `status&device_id=` | حالة تفعيل جهاز |
| `activate` | تفعيل كود على جهاز (POST: code + device_id) |

التطبيق يعمل **حتى بلا خادم**: كتالوج مدمج في `assets/data/catalog.json`
يُستبدل تلقائياً بما يصل من الـ API ويُكاش محلياً.

## التشغيل

### 1) الـ PHP (أي استضافة PHP 8+ مثل serv00)
```
1. ارفع مجلد php/ كاملاً إلى موقعك (مثال: public_html/bluevip/php)
2. افتح https://موقعك/bluevip/php/admin/ → سجل دخول
3. غيّر كلمة المرور من الإعدادات
4. القاعدة تنشأ تلقائياً في php/data/bluevip.db
```

### 2) التطبيق
```
1. عدّل app/lib/config.dart → apiBase ليطابق رابط مجلد php
2. ارفع الكود أو استخدم بناء الـ Actions الآلي
3. الـ APK يظهر في Releases باسم blue-vip.apk
```

### 3) نظام الاشتراك
```
1. اللوحة → أكواد VIP → ولّد دفعة (عدد + مدة)
2. أرسل الكود للمشترك — يدخله في التطبيق → يُربط بجهازه
3. إعادة تعيين الكود تفك الجهاز ويسمح بإعادة البيع
4. لتحويل التطبيق كلياً لمدفوع: الإعدادات → «إجبار تفعيل VIP» = مفعّل
```

## البنية التقنية

- **Flutter** + `video_player` (ExoPlayer — HLS/M3U8) + `http` + `shared_preferences`
- **PHP 8** + **SQLite (PDO)** — بلا MySQL ولا تبعيات خارجية
- GitHub Actions: بناء وثنائي ABI (`blue-vip.apk` 64-bit + `blue-vip-arm32.apk`)

## الحماية

- كلمات مرور مدير بـ `password_hash` + جلسات + **CSRF token** لكل عملية
- الكود مربوط بجهاز (device_id) + تحقق انتهاء صلاحية بالخادم
- بيانات الاتصال بـ API داخل `config.dart` فقط (بلا مفاتيح بالواجهة)
